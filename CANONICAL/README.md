## Reader instructions

- Read the whole source before evaluating a fragment.
- Quote exact wording and identify the version.
- Do not treat a summary, nearby page, or remembered reconstruction as the canonical object.
- Do not silently correct spelling, punctuation, capitalization, line endings, or terminology in the source.
- Put proposed corrections in an Issue or separate proposal record.
- Check [CANONICAL-INDEX.md](../CANONICAL-INDEX.md) and [MANIFEST.sha256](../MANIFEST.sha256) before calling a file canonical.
