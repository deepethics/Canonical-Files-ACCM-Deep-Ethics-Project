# Canonical Change Proposals

This area explains how to suggest an improvement without editing a canonical file.

Use the repository's **Canonical change proposal** Issue form. Keep the source quotation and the proposed replacement separate.

A useful proposal identifies:

- canonical ID, file path, and version;
- exact current wording;
- proposed wording or action;
- why the proposal may improve correspondence, clarity, provenance, or integrity;
- supporting source or evidence;
- possible effects on neighboring terms or pages;
- whether the matter can remain open.

## State transitions

`Proposed → Under consideration → Accepted for John's manual edit / Declined / Left open`

Only John's manual publication and the corresponding index/checksum update change the canonical object.

Issue comments, pull requests, A.I. outputs, summaries, and votes do not acquire canonical authority.
