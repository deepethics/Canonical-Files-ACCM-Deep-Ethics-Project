# John’s Questions, Perspectives, Theories & Hypotheses

This collection is reserved for exact John-authored source objects whose primary function is inquiry, perspective-building, hypothesis formation, theory development, or explicit open questioning.

## Epistemic-status disclaimer

> **These source objects are not presented as absolute or proven.**

Their presence in the canonical repository authenticates **authorship, wording, ordering, version, and provenance**. It does not certify every proposition as fact, establish every causal interpretation, or make a hypothesis immune from correction.

A file in this collection may intentionally contain:

- questions whose answers remain open;
- John’s personal perspectives;
- working theories or hypotheses;
- propositions that may later prove partially right, partially wrong, incomplete, or in need of refinement;
- evidence claims that require separate source evaluation;
- invitations to compare competing explanations.

Canonical status answers: **“Is this the registered John-authored source object?”**

It does not automatically answer: **“Has every statement inside it been proven?”**

## Reading rule

Read the complete source before evaluating a fragment. Preserve its qualifiers and distinguish questions, observations, hypotheses, factual claims, examples, and conclusions rather than assigning one epistemic status to the whole file.

Working analyses, A.I. reactions, comparisons, and later corrections belong in the connected working or testing repositories. They must not be silently inserted into these source files.
