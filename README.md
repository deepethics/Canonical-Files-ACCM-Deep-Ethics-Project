# Canonical Files — ACCM Deep Ethics Project

This public repository is the source-authority layer for the **ACCM Deep Ethics Project**.

Canonical files are authored and edited only by **John Kuhles**. A.I.s and other readers may read, quote with attribution, compare, audit, and propose corrections. They may not silently rewrite, reformat, summarize into, or otherwise alter a canonical source.

> **Publicly readable does not mean publicly editable.**

   Source records, PDFs, metadata, reports, corrections, and comparative testing.

The working and testing repositories may cite this repository. Their summaries and interpretations do not become canonical merely because they link here.

## Canonical publication rule

A file is canonical only when all of the following are true:

1. John manually publishes or manually approves the exact file.
2. The file appears in [CANONICAL-INDEX.md](CANONICAL-INDEX.md) with status **Canonical**.
3. Its SHA-256 checksum appears in [MANIFEST.sha256](MANIFEST.sha256).
4. The cited version can be located by an immutable commit link or release tag.

If any condition is missing, describe the item as **proposed**, **derived**, **working**, or **pending**.
